# Recovery gain across operating points

Companion landing page for the ICASSP manuscript **Recovery Gain Is Operating-Point Dependent in Pruned Text-to-Audio Diffusion**.

The manuscript is self-contained. This repository provides the audit and reproduction layer, including frozen protocols, per-prompt result artifacts, scoring scripts, robustness analyses, and expanded numerical results.

Start with [`../PAPER_COMPANION.md`](../PAPER_COMPANION.md) for the paper-to-artifact map and [`../PAPER_EXPANDED_RESULTS.md`](../PAPER_EXPANDED_RESULTS.md) for the full numerical layer.
